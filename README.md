# JobHub - 关注招聘信息聚合平台

## ✨ 功能特性

### 📋 核心功能
- **手动录入** — 支持录入企业名称、招聘 URL、分类标签、描述信息
- **分类管理** — 预设 10+ 分类（国央企、银行、证券、基金、互联网等），支持动态增删
- **分类筛选** — 顶部标签栏一键切换分类，实时过滤结果
- **企业搜索** — 按企业名称实时模糊搜索
- **编辑 / 删除** — 支持修改失效链接或移除冗余条目

### 🔍 URL 一键拨测
- **一键拨测** — 批量检测所有招聘链接可用性
- **三层检测策略** — CORS 代理拿状态码 → no-cors 降级 → 标记不可达
- **逐条慢检** — 1.5s/条的检测节奏，避免请求风暴
- **状态汇总** — 实时显示 🟢正常 / 🟡存疑 / 🔴失效 数量
- **失效聚焦** — 点击「失效」标签一键筛选所有不可用链接，方便集中修复
- **自动拨测** — 页面加载后自动运行（可在工具栏开关）

### 🎨 视觉设计
- 深色科技风格（Cyberpunk / Glassmorphism）
- 霓虹发光边框 + 毛玻璃面板
- 动态光晕 + 网格背景动画
- 各分类独立色彩标签
- 完整响应式布局（桌面 / 平板 / 手机）

### 💾 数据方案
- `data.json` 作为初始数据源
- `localStorage` 持久化用户变更（新增、编辑、删除、拨测结果）
- 智能合并逻辑：数据源新增条目自动同步到本地，不覆盖用户编辑
- 支持一键导出 JSON 备份

## 📖 使用指南

### 添加企业

1. 左侧表单填写企业名称、招聘网址、选择分类、描述
2. 如需新建分类，点击分类下拉框旁的 `+` 按钮
3. 点击 **「🚀 添加企业」**

### 分类管理

- 左侧「分类管理」面板可查看所有分类
- 输入新分类名称点击「添加」
- 点击分类标签上的 `×` 可删除（需先清空该分类下的企业）

### 拨测链接

1. 点击工具栏 **「🔍 一键拨测」**，开始逐条检测
2. 每张卡片的 URL 旁显示状态指示灯：
   - 🟢 绿色脉冲 = 正常
   - 🟡 黄色 = 存疑（服务器在线，页面状态未知）
   - 🔴 红色 = 失效（404 / 500 / 不可达）
   - ⚫ 灰色 = 未检测
3. 点击汇总标签（如「失效 3」）可只显示对应状态的卡片

### 修复失效链接

1. 点击「失效」标签筛选出不可用的链接
2. 点击卡片上的 **「编辑」** 按钮
3. 修改 URL 后保存

## 📊 数据结构

`data.json` 结构如下：

```json
{
  "categories": ["国央企", "银行", "证券", "..."],
  "companies": [
    {
      "id": "1",
      "name": "企业名称",
      "url": "https://zhaopin.example.com",
      "category": "分类标签",
      "description": "描述信息",
      "addedDate": "2026-06-01"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 唯一标识 |
| `name` | string | 企业名称 |
| `url` | string | 招聘网站 URL |
| `category` | string | 所属分类 |
| `description` | string | 补充描述（可选） |
| `addedDate` | string | 添加日期（YYYY-MM-DD） |

## 🌐 部署到 Vercel / Netlify

项目为零依赖的纯静态页面，可直接部署到任意静态托管平台。

### Vercel

1. 将项目推送到 GitHub 仓库
2. 在 [vercel.com](https://vercel.com) 导入该仓库
3. 无需任何配置，直接点击 **Deploy**

### Netlify

1. 将项目推送到 GitHub 仓库
2. 在 [netlify.com](https://netlify.com) 选择 **Import from Git**
3. 无需构建命令，发布目录留空，点击 **Deploy site**

> 提示：部署前可将 `data.json` 中的示例数据替换为你自己的企业列表。
